# ArgoMatrix-AI
# Based Agricultural Loan Credit Scoring System

## Project Description

The AI-Based Agricultural Loan Credit Scoring System is a machine-learning-based web application designed to assess the creditworthiness of farmers.

The system analyzes agricultural and financial information such as land size, annual income, existing loans, repayment history, crop success rate, and weather risk.

It generates an estimated credit score, risk level, and loan assessment.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Scikit-learn
- Random Forest Machine Learning

## Features

- Farmer Registration and Login
- Farmer Credit Assessment
- AI-Based Credit Score Prediction
- Loan Assessment
- Risk Factor Identification
- Farmer Dashboard
- SQLite Database
